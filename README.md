# HNH Smart Field Map — الإصدار 2.0
نظام الملاحة الإسعافية الذكية في ساحات المسجد النبوي — مستشفى الحياة الوطني

## محتويات الحزمة
| الملف | الوظيفة |
|---|---|
| `index.html` | المنصة كاملة (الخريطة + الملاحة + أدوات البيانات الميدانية) |
| `sw.js` | العمل دون اتصال (يحفظ المنصة على الجهاز بعد أول فتح) |
| `manifest.webmanifest` + الأيقونات | الإضافة إلى الشاشة الرئيسية كتطبيق (PWA) واستقبال المواقع المُشارَكة |
| `field-data.json` (تُضيفه لاحقًا) | البيانات الميدانية المعتمدة لجميع الفرق |

## التشغيل عبر GitHub Pages (رابط HTTPS مجاني)
تحديد الموقع بـGPS والعمل دون اتصال **لا يعملان إلا عبر رابط HTTPS**.
1. أنشئ مستودعًا جديدًا (مثل `hnh-field-map`) وارفع جميع ملفات هذه الحزمة إلى جذره.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. بعد دقيقة يظهر الرابط: `https://<اسم-الحساب>.github.io/hnh-field-map/`
4. افتحه في Safari أو Chrome، اسمح بالموقع، ثم «إضافة إلى الشاشة الرئيسية».

## ما يعمل فعليًا الآن
- خريطة تفاعلية مبنية على المخطط الإرشادي (تكبير، سحب، تكبير بإصبعين، تدوير: كما في المخطط / الشمال للأعلى / اتجاه الحركة).
- نقطة زرقاء حيّة من GPS مع دائرة الدقة واتجاه الحركة، وتنبيه عند قِدم الموقع (أكثر من 15 ثانية)، وتعديل الموقع يدويًا (على الخريطة / من نقطة تمركز / من بوابة).
- تحديد الحالة بخمس طرق: الضغط على الخريطة، رقم البوابة (يقبل الأرقام العربية)، اسم المعلم، الإحداثيات (عشرية أو درجات/دقائق)، روابط Google/Apple Maps، واستقبال موقع مُشارَك من تطبيق آخر (أندرويد بعد التثبيت)، مع التحقق من وقوعه داخل نطاق الخريطة.
- حساب مسار حقيقي (Dijkstra) على شبكة ممرات قابلة للتحرير، بوضعين: عربة القولف / المشاة. لا تدخل عربة القولف أي مقطع غير مصرّح لها. المسارات داخل المسجد للمشاة فقط وبتفعيل «التصريح الاستثنائي».
- واجهة توجيه: تعليمات انعطاف، مسافة متبقية، وقت تقديري، صوت عربي، إعادة حساب تلقائية عند الخروج عن المسار (فقط إذا كانت دقة GPS ≤ 25 م).
- إذا لم يوجد مسار ضمن الشبكة، يرفض النظام رسم خط مستقيم ويوضح السبب.
- أدوات المشرف: المعايرة، محرر الشبكة، المواقع ونقاط التمركز، تصدير/استيراد البيانات.
- وضع تدريب يحاكي الحركة على المسار لتدريب الفرق الجديدة.
- واجهة عربية أساسًا مع الإنجليزية.

## ما يحتاج بيانات ميدانية قبل الاستخدام التشغيلي
| البند | الحالة الحالية | المطلوب |
|---|---|---|
| المعايرة (ربط المخطط بالأرض) | افتراضية تقريبية جدًا؛ قد يتجاوز الخطأ 50 م | 4–6 نقاط تحكم موزعة على أطراف الساحات |
| شبكة الممرات (60 مقطعًا) | **مسودة** مرسومة من المخطط | السير على كل مقطع بعربة القولف ثم «اعتماد» أو «إغلاق» أو تعديل |
| بوابات المسجد (1–42) | أماكن تقريبية وفق الترتيب المنشور للأبواب | تثبيت كل بوابة بـGPS |
| بوابات الساحات ودورات المياه | غير مضافة — أرقامها غير مقروءة في صورة المخطط المتاحة | ملف PDF الأصلي للمخطط، أو إدخالها ميدانيًا |
| نقاط التمركز والعيادات ومواقف الإسعاف | لا توجد | إضافتها وتثبيتها بـGPS |
| سرعات القولف والمشي (للوقت التقديري) | 10 و4.5 كم/س افتراضيًا | قياسها في التجارب الميدانية |

## خطة العمل الميداني المقترحة
1. **المعايرة:** القائمة ← البيانات الميدانية ← المعايرة ← «إضافة نقطة تحكم». قف في زاوية واضحة، اضغط مكانها على الخريطة، ثم «التقاط GPS (10 ث)». كرر في 4–6 أماكن متباعدة. الهدف: متوسط خطأ ≤ 5 م (يظهر في الشريط العلوي).
2. **الشبكة:** شبكة الممرات ← «فتح محرر الشبكة». اضغط على أي مقطع لتحديد حالته (مسودة/متحقق/مغلق) والسماح للقولف أو المشاة أو تعليمه «مزدحم». «رسم ممر» يضيف ممرات جديدة. زر 📡 GPS على أي نقطة يثبتها بإحداثياتها الحقيقية.
3. **المواقع:** ثبّت البوابات بـGPS، وأضف نقاط التمركز والعيادات ونقاط تسليم المرضى ومواقف الإسعاف.
4. **النشر لجميع الفرق:** البيانات ← «تصدير / تنزيل» ← ارفع الملف باسم `field-data.json` بجانب `index.html` في المستودع. كل الأجهزة تحمّل النسخة الأحدث تلقائيًا عند الفتح.
5. **التجربة:** قارن المسارات المقترحة بالطرق الفعلية، واقفل أي مقطع غير صالح، قبل اعتماد المنصة تشغيليًا.

## تنبيه سلامة
لا تُعتمد المنصة للملاحة الإسعافية الفعلية قبل اكتمال المعايرة واعتماد شبكة الممرات ميدانيًا. التعليمات الميدانية وتوجيهات هيئة الهلال الأحمر السعودي هي المرجع دائمًا.
